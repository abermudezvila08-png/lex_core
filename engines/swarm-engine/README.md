# Swarm Consensus Engine (Deliberación Multi-Agente Jurídico)

El **Swarm Consensus Engine** orquesta un proceso deliberativo estructurado entre agentes con roles y perspectivas dialécticas diferenciadas.

## Capacidades Principales
- **Roles Dialécticos Formalizados:**
  1. *Agente Fiscal / Regulatorio:* Postura tuitiva del interés público y rigor en el cumplimiento.
  2. *Agente Defensor / Asesor:* Garantismo procesal, excepción de fondo y favorabilidad.
  3. *Agente Auditor / Epistémico:* Control estricto de evidencia y verificación de fuentes oficiales.
  4. *Agente Magistrado / Sintetizador:* Resolución y fallo fundamentado en precedentes y norma aplicable.
- **Protocolo de Consenso:** Ponderación argumentativa sin alucinaciones, exigiendo citas exactas a gacetas y artículos verificados.
- **Trazabilidad del Dictamen:** Registro del debate y disensos minoritarios.
