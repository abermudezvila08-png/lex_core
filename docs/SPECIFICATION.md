# Especificación Operativa Maestra — VERBUM LEX CORE

1. **Regla Cero**: Estabilidad absoluta del núcleo de código validado.
2. **Epistemología**: HECHO ≠ NORMA ≠ EVIDENCIA ≠ INTERPRETACIÓN ≠ INFERENCIA ≠ CONCLUSIÓN.
3. **Anti-Alucinación**: No inventar normas; si un registro no existe, responder `NO ENCONTRADO / NO VERIFICADO`.
4. **Inmutabilidad**: No sobrescribir ante discrepancia; emitir `CONFLICTO_DE_EVIDENCIA`.
